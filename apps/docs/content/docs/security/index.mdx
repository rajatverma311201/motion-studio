Most of the web hands you a string after login and trusts it on the next request. This course opens that string up: what a token contains, why anyone can read it, how a signature proves it was not changed, and where encoding stops and real encryption begins.

## What you will learn

- A JWT is a header, a payload and a signature joined by dots.
- The header and payload are Base64URL text, not encrypted, so anyone can decode them.
- The signature is made with a secret key and proves the token was not changed.
- Changing the payload breaks the signature, so the server rejects the token.
- Signed is not secret: never put passwords or private data in a JWT.
