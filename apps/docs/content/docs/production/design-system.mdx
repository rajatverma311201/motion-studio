This page describes the **video** design system. The docs site does not use it: it uses the stock Fumadocs look with Fumadocs' built-in light/dark toggle, so do not carry these colours or shadows into `apps/docs`.

Every video frame reads its look from a theme: colours, radii, border widths, shadow style and HUD chrome. The default is Neubrutal dark — a near-black canvas, cream borders, flat accent fills and hard offset shadows — but the same components render the other themes without changes.

## Palette

Colours are data. Every file in `packages/video-kit/src/themes/` declares a complete colour set for `dark` and `light`, and the kit reads the active variant through `colors`. The rows below show the default theme, `neubrutal`.

The docs site is deliberately independent: it uses the stock Fumadocs neutral palette in both light and dark mode. Theme changes affect the videos, never the docs chrome.

The `neubrutal` dark slots and what they mean to the kit:

| Token            | Value                 | Used for                                   |
| ---------------- | --------------------- | ------------------------------------------ |
| `bg`             | `#0B0B10`             | Video background                           |
| `surf` / `surf2` | `#15151D` / `#1F1F2B` | Cards, panels, code panels                 |
| `ink`            | `#F4F1EA`             | Cream borders, body text on dark           |
| `lime`           | `#C6FF3D`             | Primary accent, title slabs, links         |
| `pink`           | `#FF4D8D`             | Warnings, errors, the second headline copy |
| `cyan`           | `#3DE3FF`             | Secondary accent, info callouts            |
| `yellow`         | `#FFD23D`             | Highlights and status tags                 |
| `violet`         | `#9B7BFF`             | Shadows under title slabs and cards        |
| `orange`         | `#FF8A3D`             | Tree row pointers and cost warnings        |
| `red`            | `#FF4D4D`             | Mistakes and unsafe operations             |

Light variants use darker accents and a paper or white background; the swatch rows above show both. The accent names are semantic slots, not literal hues: `lime` means positive, `red` danger, `cyan` info, `yellow` warning, `pink` secondary highlight, `violet` structure and `orange` attention.

## Themes

A theme is one TypeScript file with both variants plus its fonts, shape and HUD settings. `pnpm sync:themes` copies the ids, names and colours into `apps/docs/src/generated/themes.json`; this table is generated from that file.

<ThemeTable />

- Change the default for every video in `video.config.json`.
- Set a permanent look for one lesson with `theme` and `mode` in its `chapters.json`.
- Override a session with `pnpm studio --theme <id> --mode <dark|light>`, or with `#theme=<id>&mode=<mode>` on the editor URL.

The full precedence and the render steps are in [Render a video in a look](/docs/production/render-in-a-look).

## Type

| Role                      | Family             | Where                             |
| ------------------------- | ------------------ | --------------------------------- |
| Headlines, body, captions | **Space Grotesk**  | `fonts.sans` in the default theme |
| Labels, code, HUD pills   | **JetBrains Mono** | `fonts.mono` in the default theme |

Other themes declare their own stacks; `JetBrains Mono`, Roboto Mono and IBM Plex Mono all keep the 0.6 em advance the code panel depends on. The studio injects the active theme's Google Fonts stylesheet at module load through `loadFonts()`. This is not cosmetic: Motion Canvas measures text when a `Txt` node is created, so loading fonts after the first frame leaves the intro titles shifted. Keep the module-scope `loadFonts()` call in every `scene.tsx`.

## Rules

1. **Borders come from the theme.** Videos use `borderWidth()` because they are scaled down in the player. A theme with `borderWidthScale: 0` draws none. The docs use Fumadocs' own borders.
2. **Shadows come from the theme.** Neubrutal uses hard offset shadows with no blur; notebook uses soft shadows, tokyo-night has none. The kit's `boxStyle()` builds the matching stroke and offset. No ad-hoc `box-shadow` blur.
3. **Flat fills.** Accents are solid colours; gradients are reserved for the faint grid and the transparency checkerboard.
4. **Text on accents uses `colors.onAccent`.** HUD chrome uses `colors.onBrand`, not `colors.onAccent`.
5. **One accent per element.** A card has one border colour and one shadow colour; do not stack two accents on the same edge.
6. **Mono for labels, sans for speech.** HUD labels are upper-case mono with wide letter spacing; narration is sentence case in the caption bar.

## video-kit components

Every component below is exported from `@motion-studio/video-kit` and documented with a JSDoc example in its source file.

| Component                         | What it does                                                                                        | Source                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `titleBlock` / `titlePill`        | Solid accent slab, plain title or pill in the theme's title style; dark text and a themed shadow.   | `packages/video-kit/src/components/title-block.tsx`           |
| `stackedTitle`                    | Older three-copy headline (pink and cyan behind cream); kept for the lessons that predate the slab. | `packages/video-kit/src/components/stacked-title.tsx`         |
| `chip` / `chipText`               | Small neubrutalist chip with centred text, plus access to its `Txt` so the label can change.        | `packages/video-kit/src/components/chip.tsx`                  |
| `label`                           | Plain mono label with optional left/right alignment.                                                | `packages/video-kit/src/components/label.tsx`                 |
| `card`                            | Dark rectangle with a coloured hard shadow; the base shape for diagrams.                            | `packages/video-kit/src/components/card.tsx`                  |
| `statCard`                        | Big-number card with a mono title and a live `val` text node for `countTo`.                         | `packages/video-kit/src/components/stat-card.tsx`             |
| `accountCard`                     | Bank-account card with a letter tile, a balance and a hidden status tag.                            | `packages/video-kit/src/components/account-card.tsx`          |
| `titledPanel`                     | Panel with a mono title in its top bar, used for WAL and data-file diagrams.                        | `packages/video-kit/src/components/titled-panel.tsx`          |
| `logRow`                          | Fixed-height mono row with a coloured outline for log entries.                                      | `packages/video-kit/src/components/log-row.tsx`               |
| `timelineLane`                    | Dashed timeline lane with a coloured label tile on the left.                                        | `packages/video-kit/src/components/timeline-lane.tsx`         |
| `bulletRow`                       | Rounded bullet row that starts transparent for a staggered fade-in.                                 | `packages/video-kit/src/components/bullet-row.tsx`            |
| `indexLegend`                     | Legend for the tree scenes: internal node, leaf node, row pointer.                                  | `packages/video-kit/src/components/legend.tsx`                |
| `miniTree`                        | Two-level tree (one root, three leaves) with highlightable rows; cheaper than `TreeView`.           | `packages/video-kit/src/components/mini-tree.tsx`             |
| `highlightStroke` / `clearStroke` | Highlight or reset a mini-tree row or leaf border.                                                  | `packages/video-kit/src/components/mini-tree.tsx`             |
| `codePanel`                       | Syntax-coloured code panel with a title bar and a highlight bar.                                    | `packages/video-kit/src/components/code-panel/code-panel.tsx` |
| `tokenize`                        | Tokenizer behind `codePanel` for SQL, Java and query plans.                                         | `packages/video-kit/src/components/code-panel/tokenizer.ts`   |
| `focusLine` / `revealLines`       | Move the highlight bar to one line or reveal the panel line by line.                                | `packages/video-kit/src/components/code-panel/line-focus.ts`  |

The HUD is a separate folder: `say()` writes the caption bar, `buildHud()` draws the title and chapter pills, `setSection()` advances them, and `leave()` fades a section out and removes it. The tree engine lives in `packages/video-kit/src/tree` and the lesson factory in `packages/video-kit/src/lesson`.

```tsx
import {chip, colors, leave, say, titleBlock} from '@motion-studio/video-kit';

const title = titleBlock({text: 'DB INDEXING'});
const tag = chip('B+TREE', colors.cyan);
```
