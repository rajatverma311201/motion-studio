<p className="eyebrow">Motion Studio</p>

Motion Studio is a small collection of animated explainers about the software ideas that are hard to picture from text alone. Each lesson is a short video with a written page beside it: the same ideas, in order, with the code and the edge cases.

## How to use the lessons

1. **Watch the video.** No voice-over: a caption bar carries the narration.
2. **Jump to a chapter.** Every video is split into labelled sections.
3. **Read the notes.** Each lesson page repeats the argument and adds a cheat sheet, common mistakes, and SQL you can run.

The videos are not embedded yet. The preview box at the top of each lesson is a placeholder until the player lands.

<Callout title="Start with databases" type="info">

</Callout>
